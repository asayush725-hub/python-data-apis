# Python Data & APIs

A Python data analysis application that fetches data from a REST API, cleans and aggregates it with **NumPy** and **Pandas**, plots charts with **Matplotlib** and **Seaborn**, and exports a report[span_1](start_span)[span_1](end_span).

## Key Objectives Covered
1. Learn data analysis fundamentals using NumPy and Pandas library dataframes[span_2](start_span)[span_2](end_span).
2. Perform data cleaning, manipulation, and visual plotting using Matplotlib/Seaborn[span_3](start_span)[span_3](end_span).
3. Learn to consume REST APIs using HTTP requests in Python and process JSON payloads[span_4](start_span)[span_4](end_span).
4. Build a Python Data Analysis Application: dataset loading, cleaning, analysis, and report generation[span_5](start_span)[span_5](end_span).

## Folder & Output Structure
- `app.py` — Main script that runs API fetching, data cleaning, analysis, chart plotting, and report generation[span_6](start_span)[span_6](end_span).
- `requirements.txt` — Required Python libraries[span_7](start_span)[span_7](end_span).
- `.gitignore` — Files and folders excluded from Git[span_8](start_span)[span_8](end_span).
- `outputs/cleaned_dataset.csv` — Cleaned dataset saved after running `app.py`[span_9](start_span)[span_9](end_span).
- `outputs/daily_summary.csv` — Daily aggregated statistics saved after running `app.py`[span_10](start_span)[span_10](end_span).
- `outputs/analysis_chart.png` — Visual charts generated by Matplotlib and Seaborn[span_11](start_span)[span_11](end_span).
- `outputs/report.md` — Summary report generated by `app.py`[span_12](start_span)[span_12](end_span).
